# Igniter

A tiny, single-file, in-browser tool that repacks a `.bin` into a `.dat` for use with an SX Pro dongle.

[https://demoniskk.github.io/Igniter/](https://demoniskk.github.io/Igniter/)

No installs, no server, runs entirely in your browser via the Web Crypto API. Nothing leaves your machine.

## Usage

1. Open the page (or `index.html` locally).
2. Drop in your `.bin` file.
3. Click **Build .dat**.
4. Place the file in the root of your SD card

Based on [CTCaer's Custom Payload Packer](https://web.archive.org/web/20230605180753/https://gist.github.com/CTCaer/13c02c05daec9e674ba00ce5ac35f5be).
